# 雪落时分的残响 — Echoes Before the Snowfall

日式校园恋爱视觉小说（Galgame），支持 PC 桌面端与手机浏览器（竖屏/横屏自适应）游玩。

## 快速游玩方式

### 1. 电脑游玩
- 双击 `启动游戏.bat`（推荐，自动启动本地 HTTP 服务并打开浏览器），或直接打开 `index.html`。

### 2. 手机浏览器随时游玩（GitHub Pages 方式，约 1 分钟）
1. 登录 [GitHub](https://github.com/) 并点击右上角 `+` → **New repository** 创建一个新仓库（如 `snow-echoes-galgame`，设为 Public）。
2. 在仓库页面点击 **uploading an existing file**，将本文件夹内的文件（不含 `backup` 文件夹）拖拽上传并点击 **Commit changes**。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment / Branch** 下选择 `main` 与 `/ (root)`，点击 **Save**。
4. 等待 30~60 秒后页面上方会出现 `https://你的用户名.github.io/仓库名/` 链接，用手机浏览器打开即可游玩（也可在 Safari / Chrome 中“添加到主屏幕”）。

### 3. 手机免上传直接游玩（同一 Wi-Fi 局域网）
- 双击 `手机局域网游玩.bat`，根据窗口提示的 `http://192.168.x.x:8765/index.html` 在手机浏览器输入即可开玩。
