📲 添加到手机主屏幕 · 全屏更流畅
  • iPhone Safari：点击底部 「分享 □↑」 → 下滑选择 「添加到主屏幕」，从桌面启动可全屏沉浸体验并稳定保留存档。
  • 安卓浏览器：点击菜单 「⋮」 → 选择 「添加到主屏幕 / 安装应用」。
🚀 在设置中开启 CDN 加速 · 加载不卡顿 未开启

手机直连 GitHub 若图片或音乐加载较慢，请在 「系统设置」 中开启 「GitHub 国内CDN图床加速」（或点击下方按钮一键开启），切换场景与 BGM 更流畅。
